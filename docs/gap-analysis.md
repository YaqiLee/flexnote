## 三、建议开发路线图

### Phase 1 — 基础体验补全（P0）
1. **撤销/重做**：命令模式 + 操作栈，Ctrl+Z / Ctrl+Y
2. **复制/粘贴**：Ctrl+C 序列化选中块，Ctrl+V 在鼠标位置粘贴
3. **缩放**：Ctrl+滚轮缩放画布，transform: scale() + 坐标换算
4. **全文搜索**：遍历所有笔记的 blocks.content，高亮匹配结果
5. **完善快捷键**：Ctrl+A 全选、Ctrl+D 复制、方向键微调位置

### Phase 2 — 生产力增强（P1）
6. **网格吸附 + 智能参考线**：拖拽时显示对齐辅助线
7. **连接线/箭头**：SVG path 连接两个块，支持正交/曲线
8. **右键菜单**：复制/删除/置顶/锁定/导出
9. **暗色模式**：CSS 变量切换
10. **导出 PNG/PDF**：html2canvas + jsPDF
11. **拖拽外部文件**：dragover/drop 事件处理图片导入
12. **双击空白创建文本**：快速输入工作流
13. **图层排序**：完整的上移/下移/置顶/置底
14. **组合/解组**：将多个块编组为一个单元

### Phase 3 — 高级特性（P2）
15. Markdown 快捷输入
16. 代码块（Shiki/Prism 语法高亮）
17. 手绘/墨迹（Canvas API / Perfect Freehand）
18. PDF 嵌入预览
19. 迷你地图导航
20. 版本历史（本地快照）
21. 跨设备同步（WebDAV / S3 / Tauri Cloud）
22. 实时协作（CRDT / OT）
23. 移动端适配
24. 多语言 i18n

## 四、技术债务 & 已知问题

| 问题 | 影响 | 建议 |
|------|------|------|
| contenteditable 与 v-html 冲突 | 需自定义指令绕过 Vue 响应式 | 考虑迁移到 ProseMirror/TipTap |
| 无操作历史栈 | 误操作无法撤回 | 实现 Command Pattern + Undo Stack |
| 坐标计算依赖 getBoundingClientRect | 缩放后需重新换算 | 引入统一的屏幕↔画布坐标转换函数 |
| 块 z-index 仅递增 | 长期使用后数值膨胀 | 定期重排或使用浮点 z-index |
| 无性能优化 | 大量块时渲染卡顿 | 虚拟滚动 / Web Worker / Canvas 渲染 |
| 存储为单 JSON 文件 | 大文件读写慢 | 拆分为 per-note 文件或 SQLite |

## 五、竞品亮点参考

- **OneNote**：无限画布 + 墨迹手写 + OCR 图片文字识别 + 录音同步笔记
- **Notion**：数据库视图 + AI 写作 + 模板生态 + Block 嵌套
- **Obsidian Canvas**：双向链接 + 图谱视图 + 插件生态 + 本地优先
- **Miro**：实时协作 + 丰富模板库 + 投票/计时器 + 企业集成
- **Apple Freeform**：原生流畅度 + Apple Pencil + iCloud 同步 + 协作
- **Heptabase**：卡片笔记 + 白board + 大纲三视图联动 + AI 辅助
